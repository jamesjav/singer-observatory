## 一句话看懂：这是什么？

这是一颗**按此刻真实时间运转的 3D 地球**：

- 地表亮起的**微点与引线**，是此刻全世界正在发生的**真实新闻**（BBC、半岛、卫报、联合国新闻等，每 15 分钟自动更新）；
- 扩散的**蓝灰细环**，是全球 24 小时内刚刚发生的**真实地震**（USGS 震中数据）；
- 明暗交界线，是此刻**真实的太阳日照与黑夜阴影**；
- **点击地球任意角落**，即可实时读出当地此刻的气温、风速、气压与云量（Open-Meteo）。

---

## 为什么做成「歌者文明」视角？

- **人类的执念（黑格尔与福山）**：两百年前，黑格尔相信历史将在理性中走向完满与静止；冷战后，福山宣告意识形态迎来了“历史的终结”。跨越两百年，人类总习惯把自己眼前的制度、战争与输赢当成宇宙的中心。
- **宇宙的冷眼（《三体》歌者文明）**：但如果把镜头退远到《三体》中歌者文明的视角，地球只是猎户臂边缘一颗普通的岩质行星。我们每天吵翻天的国际新闻与悲欢，全都被装在厚仅 100 公里（不到地球半径 **1.57%**）的薄薄空气层里。在宇宙尺度上，人类轰轰烈烈的“历史”只是一阵微弱噪音，甚至随时可能被一片“二向箔”像归档文件一样顺手抹平——**清理，只是一份普通的工作。**
- **这个作品的意义**：把人类此刻的喧嚣与冷漠的太阳、大气、地壳并置在一起，不是为了虚无，而是让我们在看见自身的渺小之后，更觉黑夜里每一簇微弱灯火的脆弱与珍贵。

## 界面黑话对照 & 怎么玩

画面刻意保留了冰冷的“高维观测终端”术语，第一次打开可以按这张表对照（网站左上角点 **「关于作品 ?」** 也能随时查看）：

| 界面显示 | 实际含义 / 怎么互动 |
|---|---|
| **表面噪音流**（白色/琥珀微点与引线） | 全球多源实时新闻；点击列表或地球上的引线可飞往事发地并跳转原文 |
| **地壳微震**（蓝灰扩散细环） | USGS 全球 24 小时真实地震（震中位置、震级、深度） |
| **薄层大气扰动** | 点击地球任意位置，实时获取该点气温、风速、风向、气压与云量 |
| **恒星入射点 / 底部时间轴** | 此刻太阳正午直射点；底部可暂停或加速观看真实日照阴影扫过地表 |
| **深空退远（暗淡蓝点）** | 镜头拉远至地月轨道之外，地球缩成微尘，所有噪音归于沉寂 |
| **清理预演 · 二向箔** | 体验三维地球连同灯火与新闻缓慢展平为二维星图的可逆艺术演出（随时可复原） |
| **静默巡航 (`H`)** | 隐藏所有文字 HUD，纯享无干扰深空环绕观测（移到屏幕边缘或按 `H` 恢复） |
| **声景 / 静音** | 开启或关闭程序合成的深空环境低鸣（默认严格静音） |
| **混沌相空间（地球下方）** | 实时新闻 API 冲突/地震熵值耦合洛伦兹吸引子与三体引力轨道，支持双轨蝴蝶效应分叉与点击新闻注入微扰 |

## 本地运行与自动化部署

需要 Node.js 24+：

```bash
npm install
npm run build
npm start
# 打开 http://127.0.0.1:5192/
```

### 自动化更新架构
- **`.github/workflows/update-news.yml`**：每 15 分钟抓取 6 个真实来源，生成静态快照 `data/news.json` 推送至 `gh-pages`（不污染 `main` 分支）。
- **`.github/workflows/deploy-pages.yml`**：推送 `main` 时自动运行全部单元测试（459 项）、构建并部署到 GitHub Pages。
- **Qoder Sites 静态托管对接**：只需在构建环境变量中配置 `VITE_NEWS_API_URL=https://jamesjav.github.io/singer-observatory/data/news.json` 和 `VITE_BASE_PATH=/`，即可零后端直接使用每 15 分钟更新的真实数据。
